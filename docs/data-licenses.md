# Language-model data: sources, licences and what was used

The language packs in `app/src/main/assets/lm/` are statistics derived from the corpora below: pruned,
quantised n-gram probabilities, word frequencies and spelling-variant preferences. No corpus text is
shipped. The machine-readable manifest is `tools/lm/sources.py`, and every download's URL and SHA-256 are
recorded in `tools/data/raw/MANIFEST.json` when the pipeline runs.

**No Gboard or SwiftKey dictionary, model or data was used** (CONTRIBUTING.md, clean-room rules).

## Licence of the shipped packs

`en.lm`, `en_GB.lmo`, `en_US.lmo` and the neural rescorer `en.nnlm` (trained on the same text streams) are
**CC BY-SA 4.0**. Wikipedia, Schema-Guided Dialogue and wordfreq
are share-alike, and every other input below is compatible with CC BY-SA. Required attributions live in
`NOTICE` and next to the assets in `app/src/main/assets/lm/LICENSE.txt`. The app's licences screen
should display that file.

Whether pruned n-gram probabilities are "adapted material" under copyright is debatable. Honouring the
licences anyway costs little.

splits of the LM's own licensed chat/web text, plus those dev splits as negatives; the reported test sets are the
held-out test splits above and the two GEC benchmarks.

## Evaluated and rejected

| source | reason |
|---|---|
| OpenSubtitles (OPUS v2018/v2024) | **No licence.** OPUS only asks for a link to opensubtitles.org, and the subtitles transcribe copyrighted films. It is the best proxy for spoken English, but nothing grants rights to derived statistics, so it is excluded. Its influence reaches us only through wordfreq's relicensed aggregate frequencies |
| Reddit-derived sets (Pushshift, webis/tldr-17, …) | Reddit's Data API terms forbid ML training without rightsholder permission, and dataset labels cannot grant rights to user posts |
| Twitter/X | ToS forbids redistribution; only wordfreq's aggregate frequencies are used |
| PersonaChat | licence is fine (CC BY 4.0 via ParlAI), but the text was lowercased and contraction-expanded ("i am", "do not"), which would bias the model against how people type |
| DailyDialog, SAMSum, original EmpatheticDialogues | NC/ND licences. DailyDialog is used for evaluation only |
| Cornell Movie-Dialogs, Ubuntu Dialogue, Enron | no licence, or unclear (and PII for Enron) |
| Stack Exchange dumps after 2024-04 | gated behind an agreement excluding LLM training. Earlier archive.org dumps (CC BY-SA) are acceptable but were not needed |
| Google Books Ngram | CC BY 3.0, usable, but literary and redundant with wordfreq |
| UCI SMS Spam Collection | CC BY 4.0, but its "ham" messages largely duplicate the NUS SMS corpus |
| Common Voice sentences | CC0, but mostly Wikipedia sentences already covered |

## Other languages: what the pipeline can use

`tools/lm/langs.py` configures locales; `build.sh de_DE`, `build.sh es_ES`, … select their corpora. The
multilingual sources and their licences:

| source | licence | coverage |
|---|---|---|
| Tatoeba | CC BY 2.0 FR | ~400 languages: large for de, fr, it, es, ru, tr, pt, ja; thin for many others |
| OpenAssistant oasst1/2 | Apache-2.0 | 35 languages; substantial es, ru, de, zh, fr, ca, pt-BR, uk |
| WildChat-1M | ODC-By 1.0 | ~68 languages; mostly en, zh, ru, fr, es, pt, de, ar, it, tr |
| Wikipedia | CC BY-SA 4.0 | 300+ languages |
| FineWeb-2 | ODC-By 1.0 | 1000+ language-script pairs. The pipeline fetches only the leading row groups of a shard over HTTP ranges |
| Leipzig Corpora Collection | CC BY 4.0 (downloadable text corpora) | 290+ languages: web, news and Wikipedia samples per country |
| wordfreq | CC BY-SA 4.0 | 44 languages; "large" lists for about 20 |
| LDNOOBW | CC BY 4.0 | ~28 languages; must be curated per language as for English |
| OPUS | per-corpus licences | a collection, not a licence. Only corpora with an explicit open licence qualify (e.g. GlobalVoices CC BY, Tatoeba, Wikimedia); OpenSubtitles, TED2020 (CC BY-NC-ND) and others do not |

Languages written without spaces (zh, ja, th) would also need a word segmenter before tokenisation; none
is configured yet.
